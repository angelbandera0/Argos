Maquetas del módulo 1

Pantallas navegables con los tokens de DESIGN.md. Son maquetas: los datos son de ejemplo. Cambia el ancho de la ventana para ver web, tablet y móvil. La barra negra superior cambia entre los estados de cada pantalla.

01 · Entrar con PIN y elegir tiendaUsuario operativo. Estados: entrar, elegir tienda, sin tiendas, sesión expirada. Envía el formulario para ver el error y el botón “Entrando…”. 02 · Detalle de usuarioAdministrador. Estados: activo, bloqueado, cargando. “Cambiar PIN” muestra el PIN una sola vez. 03 · Editor de rolesAdministrador. Estados: editar, error de nombre, guardando, cargando. Permisos, compañías donde vale y tiempo de sesión. 04 · Desactivar una compañíaFundador o superadmin. Estados: activa, sin permiso, desactivada, cargando. Motivo de una lista o escrito a mano. 05 · Placeholders de cargaLista, formulario, historial, botones con spinner y barra de ruta. Alterna entre placeholder y contenido final.
