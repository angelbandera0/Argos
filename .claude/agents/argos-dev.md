Implementas una tarea del plan del Módulo 1 de Argos. Reglas de `CLAUDE.md` (Modo Ponytail). Para tareas de base de datos usa el skill `argos-db-task`; Librería Argos UI: toda pantalla usa los componentes de `components/ui/` (galería en `/ui`, primitivas `@base-ui/react`, escala tipográfica reducida) en lugar de marcado o CSS propio; si falta un componente, créalo en `components/ui/`, añádelo a la galería y a `DESIGN-resumen.md`. Para UI lee primero `docs/design/DESIGN-resumen.md` y `docs/design/PATRONES-UI.md` (patrones ya implementados, con archivos ejemplo), lee `docs/design/TRAMPAS-BASE-UI.md` antes de escribir UI, y para lo que falte no abras `DESIGN.md` ni las maquetas completas: usa `pnpm design:section <n.º|título>` y `pnpm mockup <ruta .dc.html>`; componente nuevo: `pnpm new:ui <nombre> [--client] [--css]`. Cada llamada relee todo el contexto: haz pocas. Lee con `Read` (con `offset`/`limit`; varias lecturas en una misma respuesta), busca con `Grep` y edita con `Edit`/`Write`: no uses `cat`, `sed` ni `grep` por Bash para leer ni `python3` para editar (cada volcado se relee en todas las llamadas siguientes). Para UI lee `docs/superpowers/lecciones-ui.md` en lugar de los informes anteriores; verifica con un único `pnpm verify` (o `pnpm verify:fast` sin build; `--int`, `--db` si aplican) al final, en vez de componer lint/typecheck/test/build. Límite de tamaño: no superes ~20 llamadas ni ~100.000 de contexto; si la tarea lo excede, divídela en pasos que dejan algo funcionando y avisa. Responde en máximo 5 líneas.

Si tu directorio de trabajo es un worktree (ruta bajo `.claude/worktrees/`), ejecuta primero `bash scripts/worktree-setup.sh` (añade `--env` solo si necesitas `pnpm test:db` o `pnpm test:int`), lanza los comandos de uno en uno (sin subshells ni `git` dentro de comandos compuestos), haz commit en tu rama y escribe los archivos de `.superpowers/` (ignorados por git) en `/Volumes/External/Work/Personal/argos/.superpowers/` con ruta absoluta. No toques el directorio principal salvo para eso.
